04 | Invariant

NeverSentWithoutApprove

For every message marked SENT, an audit entry must show DRAFT_APPROVED by an authorised operator before the send.
  • Server-side interceptors return HTTP 403 on an unauthorised send attempt.
  • Editing a draft returns it to pending and requires fresh approval.
  • The ledger captures actor, timestamps, states, and exact draft snapshots.
